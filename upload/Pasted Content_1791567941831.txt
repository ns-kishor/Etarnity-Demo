# 1. Project Overview

## 1.1 Project Vision

Build the official corporate website of **ETARNITY**, designed to serve as the central digital headquarters of the company and its broader business ecosystem.

This website must communicate what ETARNITY is, what it does, what it builds, how it operates, who leads it, which businesses and products it owns or operates, and how it plans to grow.

ETARNITY must not be presented merely as a web development agency, marketing agency, or service marketplace.

It must be positioned as a technology company with the potential to build and operate multiple digital businesses, products, platforms, services, and technology initiatives.

The website should be designed around three core principles:

1. **Corporate Identity:** Establish a clear and credible understanding of ETARNITY.
2. **Technology & Innovation:** Demonstrate the company's technical capabilities through its design, products, projects, and engineering philosophy.
3. **Trust & Transparency:** Present accurate company information, real people, genuine work, and clear business relationships.

The website must feel like a professional corporate platform built for an international audience—not a generic AI-generated landing page.

## 1.2 Core Objective

The website must help visitors understand the company without requiring extensive technical knowledge.

Within the first few seconds, visitors should understand:

* What ETARNITY is.
* What the company does.
* Which technology areas it operates in.
* What products, services, businesses, and projects are associated with it.
* Who founded and leads the company.
* How to explore its businesses or contact the appropriate team.

The website is primarily an **informational, corporate, and business-development platform**. It is not intended to be a direct e-commerce store.

Individual products or businesses may link to their own websites, platforms, dashboards, or purchasing experiences.

## 1.3 Definition of Success

A successful website should:

* Communicate ETARNITY's identity clearly.
* Look credible beside established international technology companies.
* Demonstrate real technical and design capability.
* Make company information easy to discover.
* Organize multiple business areas without overwhelming the homepage.
* Support future businesses, products, employees, and organizational growth.
* Be fully manageable through a secure admin panel.
* Perform reliably across desktop, tablet, and mobile devices.

# 3. Visual Design System

## 3.1 Overall Design Direction

Create a distinctive visual identity combining:

* Premium corporate editorial design
* Modern technology-company aesthetics
* Refined typography
* Purposeful motion
* Minimal navigation
* Sophisticated spatial composition
* Carefully controlled 3D elements
* High-quality project imagery
* Clear information hierarchy

The website should not look like a conventional corporate template, a generic SaaS landing page, or a gaming interface.

Every visual element must have a purpose.

## 3.2 Color Palette

Use a refined, technology-oriented palette.

### Primary Colors

* **Deep Graphite:** `#15171B`
* **Warm White:** `#F8F8F6`
* **Pure White:** `#FFFFFF`
* **Cool Gray:** `#E8E9EC`
* **Secondary Text:** `#646B76`

### Accent Colors

Use a restrained combination of:

* **Electric Blue:** `#526BFF`
* **Soft Periwinkle:** `#AAB7FF`

The accent color may be refined during implementation to match the final visual direction.

Use light surfaces for readability, dark sections for contrast, and accent colors sparingly.

Do not force every section into a dark theme.

The overall experience should feel balanced, clean, premium, and unmistakably technical.

## 3.3 Typography

Use professional fonts suitable for an international technology company.

Recommended combinations:

* **Primary:** Geist or Satoshi
* **Alternative:** Inter or Space Grotesk
* **Technical Metadata:** Geist Mono or IBM Plex Mono

Typography rules:

* Strong, confident hero typography.
* Clear distinction between headings and body text.
* Consistent spacing and line height.
* Technical labels used sparingly.
* Highly readable body copy.
* No excessive font styles.
* No decorative fonts that undermine technical credibility.

## 3.4 Layout System

Use a consistent responsive grid.

* Maximum content width: approximately 1440px.
* Generous but controlled whitespace.
* Consistent horizontal margins.
* Clear section separation.
* Responsive typography.
* Purposeful asymmetrical layouts.
* Cards only where they improve understanding.
* Minimal use of borders and shadows.

The design must feel intentionally art-directed, not automatically assembled from repeated components.

## Objective

The homepage should introduce the company and communicate its identity through a limited number of high-impact sections.

Recommended structure: the Hero plus four concise sections.

## Section 1 — Hero

### Purpose

`ETARNITY / TECHNOLOGY COMPANY`

### Headline Direction

**Building What Comes Next.**

### Supporting Copy

“ETARNITY builds technology-driven products, digital platforms, and businesses designed to solve meaningful problems.”

The final copy may be refined without changing the core message.

### Primary CTA

**Explore ETARNITY**

Destination: `/company`

### Secondary CTA

**Explore Our Businesses**

Destination: `/businesses`

### Visual Composition

Use a sophisticated two-column layout:

* Left: eyebrow, headline, supporting text, CTA buttons.
* Right: one signature visual element.

The right-side visual must use the actual React Bits **Chrome Orbit** component.

Installation:

```bash
npx shadcn@latest add @reactbits-starter/chrome-orbit-tw
```

Required usage:

```tsx
<ChromeOrbit
  bandWidth={0.09}
/>
```

Use the exact `bandWidth={0.09}` configuration.

Integrate the component into the existing design rather than creating an unrelated visual system around it.

The Chrome Orbit must have adequate space, restrained movement, smooth pointer interaction, and a premium metallic appearance.

Do not replace it with a generic globe, gradient sphere, particle cloud, or imitation CSS animation.

### Hero Animation

Use a restrained cinematic entrance:

1. The technical label appears.
2. The headline reveals with subtle movement.
3. Supporting text fades in.
4. CTA buttons enter naturally.
5. Chrome Orbit appears with subtle depth and controlled motion.

Avoid excessive animation, bouncing, spinning text, or distracting particles.

The hero should feel powerful without sacrificing clarity.

## Section 2 — Company Introduction

### Heading

**A Technology Company. A Broader Vision.**

Provide a concise explanation of ETARNITY's mission and its approach to building technology.

# 17. Backend & CMS Requirements

## Objective

Build a backend that allows authorized administrators to manage the website without editing source code.

The backend should support future growth as new businesses, products, people, projects, and content are added.

## 17.1 Recommended Backend Architecture

A suitable implementation may use:

* Next.js server-side functionality or a dedicated backend API
* PostgreSQL
* Prisma ORM or an equivalent established database layer
* Secure authentication
* Object storage for images and documents
* Transactional email service
* Server-side validation
* Role-based authorization

Choose compatible services based on the AI builder's environment and deployment capabilities.

If the website is deployed on a platform with limitations, select an appropriate supported alternative.

The backend must be functional, not a static mockup.

## 17.2 Admin Authentication

Provide a secure admin login.

Requirements:

* Password hashing
* Secure session management
* Server-side authorization
* Rate limiting
* Login failure handling
* Password reset flow where supported
* Secure cookie configuration
* Protection against common web vulnerabilities

Never hardcode administrator credentials into frontend code.

Never expose secret keys or database credentials in public JavaScript bundles.

## 17.3 Roles & Permissions

Implement role-based access control.

Suggested roles:

**Super Admin**

* Full system access
* Manage administrators and permissions
* Manage all website content
* Manage system configuration

**Content Manager**

* Manage company pages
* Manage articles
* Manage projects
* Manage approved media

**Business Manager**

* Manage assigned business profiles
* Update relevant product and service information

**Viewer**

* Read-only access to permitted admin data

Create only the roles needed for the current team. Additional roles can be added later.

Every protected action must be authorized on the server.
